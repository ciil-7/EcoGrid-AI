# ⚡ EcoGrid-AI: Industrial Carbon Footprint & Energy Grid Balancer

## 📌 نبذة عن المشروع
مشروع ذكاء اصطناعي متطور مصمم خصيصاً لقطاعات الطاقة والاستدامة. يهدف إلى محاكاة عمليات مصانع الطاقة، تحليل معدلات استهلاك الطاقة، والتنبؤ بانبعاثات الكربون باستخدام خوارزميات التعلم الآلي (Machine Learning) لدعم أهداف الحياد الكربوني والاستدامة الذكية.

## 🛠️ التقنيات المستخدمة
* **Python**: لبرمجة وتطوير النماذج.
* **Pandas & Scikit-learn**: لمعالجة البيانات وتطبيق خوارزميات الانحدار الخطي (Linear Regression).
* **Streamlit**: لبناء واجهة تفاعلية بصرية لعرض البيانات والتحليلات.

## 📂 هيكل المشروع
* `simulator.py`: مولد بيانات وهمية لمحاكاة استهلاك الطاقة والانبعاثات.
* `model.py`: نموذج الذكاء الاصطناعي لتدريب وتحليل البيانات وتقييم نسبة الخطأ.
* `app.py`: واجهة المستخدم الرسومية لعرض لوحة المؤشرات والرسوم البيانية.
